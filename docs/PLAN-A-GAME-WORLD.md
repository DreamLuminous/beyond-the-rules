# 开发者 A 计划：游戏世界与规则执行

## 交付边界

A 交付一个完全不依赖真实 AI 的可玩版本。输入固定 `ActionPlan` 即可改变世界、通关、失败、撤销和存档。

## 任务清单

### M0：工程与协议（共同，半天）

- 确认 `LevelDefinition`、`WorldSnapshot`、`ActionPlan`、`ExecutionResult`。
- 提供三个固定计划：合法、目标不存在、越权修改。
- 建立 `worldRevision`、事务预检和撤销栈。

验收：固定 JSON 能通过执行器改变一块石头，失败计划不产生任何部分修改。

### M1：悬空之桥（1～1.5 天）

- Phaser 场景、角色移动、跳跃、碰撞、镜头。
- 三块石板、木箱、风场、压力机关、出口、隐藏洞穴。
- 实现 `physics.move/setGravity/applyForce` 与 `mechanism.setState`。
- 计划整体预检、依赖顺序、动画、撤销和通关判定。
- 两条测试解法：石板台阶；风场推动箱子触发机关。

验收：不用 AI，固定计划可完成两种解法；撤销恢复所有受影响对象。

### M1.5：第一关三任务（已完成首版）

- 任务一“第一次指导”：墨点走到第一块石板，站位由引擎判定。
- 任务二“开放式过桥”：墨点用规则笔把三块石板移到连续通路，再走到对岸。
- 任务三“意外变化”：接近装置时检修桥板缩回，墨点停在缺口前返回 `PATH_BLOCKED`；
  玩家可让它重新规划，用规则把检修石板移进缺口，再走到装置。
- 地面探测阻止墨点走进断口；任务事件、目标与提示同步到 UI；通关生成共创总结。
- 已验证：无头浏览器完整跑通三任务（422 → 918 → 停在 1411 → 补缺口 → 1650 通关）。

### M2：回声工坊（已完成首版）

- `LevelDraft` 装载器与 30×12 网格世界；平台、墙、闸门、发射器、镜子、接收器、出口、隐藏记录。
- 光路模拟：镜面 `/` 与 `\` 反射、接收器点亮、闸门联动，场景与验证器共用同一套 `beam` 计算。
- 可解性验证：枚举镜面朝向与闸门状态，带跳跃约束的可达性搜索；额外检查出生点、机关必要性、
  镜子能否按顺序接近、隐藏区域是否可达。
- 玩家操作：WASD / 方向键移动、空格跳跃、E 转动最近镜子；通关与隐藏记录事件上报 UI。
- 失败草案零载入；验证未通过的草案不得进入场景。

验收：同一份 `LevelDraft` 在验证器中“有解”，玩家能真实通关；删掉出口或封死镜子时验证器拒绝。

### M3：断流之城（系统层已完成）

- 确定性七日模拟：来水、储水、配水、发电、泵站、土壤湿度、生态与居民供水。
- 固定事件表：第 3–4 天干旱、第 5–6 天泵站故障；备用泵由玩家巡查解锁。
- 规则解释器：按顺序取第一条匹配规则，支持 `all` / `any` 条件与白名单城市动作。
- 判定由引擎给出：居民均值、每日能源、生态下限、水库安全；逐日报告 + 结局。
- 城市探索地图待实现：当前用设施面板承载巡查与隐藏信息。

验收：自适应策略通过七日检查，固定配水策略在泵站故障日失败；相同规则与选项结果完全一致。

### M4：联调与打磨（共同，1 天）

- 接入 B 的计划端点；请求期间游戏继续运行。
- 处理超时、重复请求、过期世界版本、取消与重试。
- 每次执行后输出完整 `ExecutionResult`。

## A 不负责

- 提示词与模型供应商细节；
- 语音转写质量；
- 从自然语言猜测游戏对象；
- 让执行器运行任意模型生成代码。
